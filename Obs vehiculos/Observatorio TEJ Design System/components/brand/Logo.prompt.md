The TEJ brand wordmark. No image logo was provided with the sources, so the mark is set in Raleway.

```jsx
<Logo variant="full" />            {/* stacked lockup for the header */}
<Logo variant="pill" />            {/* teal badge — hero / dashboard title */}
<Logo variant="mono" />            {/* short TEJ mark */}
<Logo variant="full" onLight={false} />  {/* on a teal background */}
```
