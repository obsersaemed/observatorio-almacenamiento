If creating visual artifacts (slides, mocks, throwaway prototypes, etc.), copy assets out and create static HTML files for the user to view. If working on production code, copy assets and read the rules here to become an expert in designing with this brand.

Brand essentials: Raleway type; teal `#4dd0e1` primary with purple `#ce93d8` as the secondary data series and peach `#f4b183` as a sparing accent; green/orange/gray/red project-status colors; a faint Colombia-departments map watermark as the signature motif; Spanish (es-CO) copy with decimal commas and units in [brackets]. No logo exists — set the name in Raleway via the `Logo` component.

If the user invokes this skill without other guidance, ask them what they want to build or design, ask a few questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
