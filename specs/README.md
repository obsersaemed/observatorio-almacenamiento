# Especificaciones

Una carpeta por funcionalidad, numerada en orden: `001-nombre-corto/`.

| Archivo | Fase | Skill |
|---|---|---|
| `brainstorm.md` | 1. Explorar la idea | `brainstorm` |
| `spec.md` | 2. Qué debe hacer y cómo se comprueba | `specdefinition` |
| `plan.md` | 3. Cómo se construye y tareas | `planwriting` |
| (tareas marcadas en `plan.md`) | 4. Construir y verificar | `implementation` |

Cada documento lleva una línea `Estado:`. Se pasa a la siguiente fase solo con el
documento aprobado por el usuario.
